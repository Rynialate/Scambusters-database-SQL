Pivot Tracker

Enter your API key once per browser tab (kept only in this tab's session storage, never sent anywhere except this API's own /api/* endpoints).

Add entry

Any supported format: "example.com pivot1 pivot2", CSV-ish, JSON, or free text.




Search


A domain to see its accumulated pivots, or a pivot value to see which domains it's linked to.







Import CSV



  One domain per row: first column is the domain, every column after it is a pivot for that row
  (rows can have different numbers of columns). A cell containing a comma, quote, or newline
  should be wrapped in double quotes, standard CSV style.

  Example:

  example.com,1.2.3.4,malicious@example.net
another-domain.com,"pivot, with a comma"









Export CSV


Downloads every domain in the database with its full accumulated pivot list, in the same layout the importer above expects.
